# 좀비 서바이벌

HTML 파일 하나로 실행하는 브라우저 기반 2D 생존 액션 게임입니다. 마우스로 조준하고 적을 처치하며, 웨이브마다 강화를 선택해 캐릭터를 성장시킵니다.

**[게임 플레이](https://sleepyjk.github.io/zombie-survival/)**

## 시작하기

1. 게임에 접속해 로비에서 세계를 선택합니다.
2. 직업을 선택합니다. 소환사 계열은 소환수도 선택할 수 있습니다.
3. **게임 시작**을 누릅니다.
4. 적을 모두 처치하고 제시되는 강화 중 하나를 골라 다음 웨이브에 도전합니다.

키보드와 마우스를 사용하는 PC 브라우저 기준입니다. 현재 터치 전용 조작 UI는 없습니다.

## 세계와 게임 모드

| 세계 | 테마 |
| --- | --- |
| 1세계 · 좀비 도시 | 좀비와의 생존 전투 |
| 2세계 · 할로윈 나이트 | 호박, 유령, 해골 테마 |
| 3세계 · 얼음왕국 | 눈사람, 얼음 정령, 예티 테마 |

각 세계에는 전용 직업과 보스가 있습니다. 생존 모드에서는 3·6·9… 웨이브마다 보스가 순서대로 등장합니다.

| 모드 | 내용 |
| --- | --- |
| 생존 | 혼자 웨이브를 돌파하며 성장 |
| PvP · AI | AI 도전자와 1:1 대전 |
| 파티 · AI | AI 동료 2명과 함께 생존 |
| PvP · 와이파이 | 친구와 2인 대전 |
| 파티 · 와이파이 | 친구와 2인 협동 생존 |

로비의 4~6세계, 각성, 1차원 이동, 길드는 잠금 상태로 표시되며 현재 플레이할 수 없습니다.

## 조작법

| 입력 | 동작 |
| --- | --- |
| `W` `A` `S` `D` 또는 방향키 | 이동 |
| 마우스 이동 | 조준 |
| 마우스 왼쪽 클릭 | 직업별 공격·소환·포탑 설치 등 |
| `R` | 탄약을 사용하는 직업 재장전; 탄약 소진 시 자동 재장전 |
| `1` `2` `3` 또는 강화 카드 클릭 | 웨이브 종료 후 강화 선택 |
| `Enter` / `Space` | 직업 선택 화면에서 게임 시작 |
| `Enter` | 게임 종료 후 다시 시작 |

대부분의 공격은 버튼을 누르고 있으면 반복됩니다. 기사는 한 번 클릭하면 베기, 빠르게 연속 클릭하면 방패 방어를 사용합니다. 실제 공격 방식과 탄약 사용 여부는 선택한 직업의 설명을 확인하세요.

## 직업과 성장

- 일반·희귀·영웅·신화·전설·GOD 등급의 직업을 선택할 수 있습니다.
- 원거리 사격, 근접 베기, 폭탄·물약 투척, 화염·냉기 공격, 포탑 설치, 소환 등 공격 방식이 다릅니다.
- 소환사 계열은 늑대·매·곰 중 소환수를 선택할 수 있습니다.
- 게임 오버 시 획득 점수가 보유 포인트에 더해지며, 포인트로 잠긴 직업을 구매합니다.
- 생존 웨이브 종료 시 현재 직업에 맞는 무작위 강화가 최대 3개 제시됩니다. 강화에는 레벨 상한이 있습니다.
- 회복 아이템을 줍고, 보스의 붉은 예고선과 원을 피해 생존하세요. 일부 적 탄환은 플레이어의 총알로 요격할 수 있습니다.

**현재 영구 저장 기능은 없습니다.** 보유 포인트, 구매한 직업, 최근·최고 점수는 페이지를 열어둔 동안 메모리에만 유지됩니다. 새로고침하거나 페이지를 다시 열면 초기화됩니다.

## 친구와 연결하기

### 방 번호 방식

1. 두 사람이 게임을 열고 로비에서 **PvP** 또는 **파티** → **와이파이**를 선택합니다.
2. 호스트가 **방 만들기**를 누르고 표시된 4자리 번호를 친구에게 전달합니다.
3. 참가자는 **방 번호로 입장**에서 번호를 입력합니다.
4. 연결 후 호스트가 세계와 직업을 선택하고 게임을 시작합니다.

호스트가 게임을 실행하고 참가자는 조작 입력을 전송하며 게임 상태를 받아 표시합니다. 호스트 페이지를 계속 열어두어야 합니다.

방 번호 방식은 PeerJS 1.5.4를 unpkg CDN에서 불러오고 공개 PeerJS 연결 서비스를 사용합니다. UI의 이름은 ‘와이파이’이지만 실제 연결은 WebRTC 기반이며, 연결 가능 여부는 양쪽 네트워크 환경과 외부 서비스 상태에 영향을 받습니다.

### 직접 코드 방식

**서버 없이 직접 코드로 연결 (고급)**을 펼쳐 사용할 수 있습니다.

1. 호스트가 **코드 방 만들기**에서 생성된 코드를 참가자에게 전달합니다.
2. 참가자는 **코드로 참가**에서 코드를 붙여넣고 **답장 코드 만들기**를 누릅니다.
3. 참가자가 답장 코드를 호스트에게 전달합니다.
4. 호스트가 답장 코드를 붙여넣고 **연결**을 누릅니다.

이 방식은 PeerJS 방 번호 서비스를 거치지 않고 코드를 직접 교환하지만, 연결 후보 탐색에는 Google 공개 STUN 서버를 사용합니다. 자체 TURN 중계 서버 설정은 없어 일부 NAT·방화벽 환경에서는 연결되지 않을 수 있습니다.

## 로컬 실행

저장소를 내려받아 `index.html`을 브라우저에서 열면 기본 게임을 실행할 수 있습니다. 빌드나 패키지 설치는 필요하지 않습니다.

로컬 HTTP 서버로 실행하려면 Python 3가 설치된 환경에서 저장소 폴더에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 <http://localhost:8000>을 엽니다. 방 번호 연결에는 인터넷이 필요하며, 온라인 공유에는 HTTPS로 제공되는 GitHub Pages 주소를 권장합니다.

## 코드 구조

게임의 HTML, CSS, JavaScript와 Canvas 렌더링은 모두 `index.html`에 포함되어 있습니다. 별도의 이미지 파일이나 빌드 도구 없이 동작합니다. PeerJS는 방 번호 연결을 사용할 때 동적으로 불러옵니다.

수정할 부분은 다음 식별자로 찾을 수 있습니다.

| 식별자 | 역할 |
| --- | --- |
| `CLASS_DEFS`, `addW2`, `addW3` | 직업 정의와 세계별 변형 |
| `CLASS_TIERS`, `ANIMAL_DEFS` | 직업 등급과 소환수 |
| `BASE_STATS`, `UPGRADES` | 기본 능력치와 강화 |
| `BOSS_TYPES`, `HALLOWEEN_BOSS_TYPES`, `ICE_BOSS_TYPES` | 세계별 보스 |
| `WORLD_INFO`, `setWorld` | 세계 테마와 전환 |
| `startWave`, `openUpgrade` | 웨이브 진행과 강화 선택 |
| `loadPeerJs`, `wifiNewPc`, `wifiHandle` | 온라인 연결과 메시지 처리 |

## 배포 및 백업

GitHub Pages는 `main` 브랜치의 루트(`/`)를 배포합니다. `index.html`을 수정해 `main`에 반영하면 Pages 배포를 통해 사이트에 적용됩니다. 배포 상태는 저장소의 Actions 및 Settings → Pages에서 확인할 수 있습니다.

- [배포 설정](https://github.com/sleepyJK/zombie-survival/settings/pages)
- [기준 버전 백업: backup-2026-10-16](https://github.com/sleepyJK/zombie-survival/tree/backup-2026-10-16)
- [백업 ZIP 다운로드](https://github.com/sleepyJK/zombie-survival/archive/refs/tags/backup-2026-10-16.zip)

백업 태그는 초기 공개 게임 버전을 보존합니다. 이후 `main`의 변경과 별도로 해당 버전의 코드를 확인하거나 내려받을 수 있습니다.
